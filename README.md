# 知识图谱推理问答（KG Chat）

一个纯前端的知识图谱智能问答网站：内置 1000+ 节点、200+ 领域的中文知识图谱，
支持多跳推理、路径搜索、关联推理，并实时可视化推理过程。

## 功能

- **大规模知识图谱**：4 大类（自然科学 / 技术与工程 / 人文社科 / 生活与文化）、
  200+ 领域、1000+ 节点、数千条关系边，页面顶栏实时显示统计。
- **图谱推理引擎**（`js/graph-engine.js`）
  - 多跳推理：从实体出发沿关系链扩展，生成可读推理链
  - 路径搜索：DFS 枚举两实体间路径并按跳数排序
  - 关联推理：共同邻居 + 领域/类别归属分析
  - 激活扩散：相关概念推荐
- **语义分析器**（`js/semantic-analyzer.js`）
  - 基于图谱词典的正向最大匹配中文分词
  - 词义消歧：同名实体按上下文领域打分选择义项
  - 同义词扩展：别名归一到规范实体名
  - 意图识别：定义 / 关系 / 对比 / 列举 / 因果 / 归属 / 探索 7 类意图
- **推理可视化**（`js/visualizer.js`）：Canvas 力导向布局，推理路径金色高亮 +
  流动粒子动画，支持拖拽节点、平移、滚轮缩放、悬停查看详情。
- **推理详情面板**：推理过程步骤、图谱可视化、语义分析三个标签页。

## 使用

无需构建，直接用浏览器打开 `index.html` 即可（或任意静态服务器，如
`python3 -m http.server`）。

## 目录结构

```
index.html          页面入口
css/style.css       样式
js/graph-engine.js  图谱构建与推理引擎
js/semantic-analyzer.js 语义分析器
js/visualizer.js    推理可视化组件
js/app.js           聊天与面板逻辑
data/kb-part*.js    知识库数据（按大类分 4 个文件）
```
